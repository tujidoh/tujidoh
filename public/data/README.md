# 同梱バスデータについて

| ファイル | 内容 | 出典 | データ年度 | ライセンス |
|---|---|---|---|---|
| `bus_routes_n07_2022.geojson` | バス路線（LineString）1,560本 | 国土交通省 国土数値情報「バスルートデータ（N07）」兵庫県・大阪府 | 2022年度（令和4年度）、メタデータ作成日 2023-03-10 | CC BY 4.0 |
| `bus_stops_p11_2022.geojson` | バス停留所（Point）1,101か所 | 国土交通省 国土数値情報「バス停留所データ（P11）」兵庫県・大阪府 | 2022年度（令和4年度） | CC BY 4.0 |

- 加工内容：北緯34.725〜34.865度・東経135.33〜135.505度（伊丹市・尼崎市北部・宝塚市南部・川西市南部・豊中市周辺）に掛かる地物のみを抽出し、GeoJSON に変換（`scripts/convert_ksj_bus.py`）。
- 出典表記：「国土数値情報（バスルートデータ・バス停留所データ）（国土交通省）を加工して作成」
- **2022年度時点のデータ**です。路線の新設・廃止・経路変更は反映されていません。
- N07 には系統名が含まれません（事業者名のみ）。系統名は P11（バス停）の属性から確認できます。
